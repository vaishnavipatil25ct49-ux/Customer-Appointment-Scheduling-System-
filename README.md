# Customer Appointment Scheduling System

## Description

A Customer Appointment Scheduling System is a software application used to manage customer appointments in an easy and organized way.

It allows customers to book appointments by entering their details, selecting a date and time, and viewing their appointment information.

## Features

- Customer registration and login
- Book appointments
- View appointments
- Update appointments
- Delete appointments
- Manage customer details
- Store appointment data in MySQL database
- Simple and user-friendly interface

## Technologies Used

- Python
- Tkinter
- MySQL
- mysql-connector-python

## Database

The system uses MySQL to store:
- Customer details
- Appointment details
- Login information

## How to Run

1. Install Python.
2. Install MySQL.
3. Install MySQL Connector:

pip install mysql-connector-python
